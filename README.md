# NYC Airbnb Statistical Analysis and Dashboard

## Overview
Statistical analysis and Power BI visualization project exploring NYC Airbnb listing prices, room types, borough trends, and inference insights.

## Dataset
- ~38K cleaned Airbnb listings
- NYC Airbnb Open Dataset
- Features include room type, borough, reviews, availability, and pricing

## Statistical Analysis
- Confidence Intervals
- Hypothesis Testing
- Price Distribution Analysis
- Room Type Comparison
- Review vs Price Relationship

## Dashboard Pages

### Market Analytics Dashboard
- Room type distribution
- Borough listing analysis
- Pricing insights
- NYC listing distribution map

### Statistical Insights Dashboard
- Confidence interval insights
- Price comparison analysis
- Reviews vs price trends
- Borough pricing comparison

- Python

- Power BI
