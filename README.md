# 🏙️ NYC Airbnb Statistical Analysis & Power BI Dashboard

End-to-end statistical analytics and business intelligence project analyzing the New York City Airbnb market using statistical inference, exploratory data analysis (EDA), and interactive Power BI dashboards.

This project combines **Data Science**, **Statistical Modeling**, and **Business Intelligence** techniques to investigate pricing patterns, room type distribution, borough trends, availability behavior, and review insights across NYC Airbnb listings.

# 📌 Project Description

The objective of this project was to perform statistical analysis and business intelligence reporting on NYC Airbnb listings and transform analytical insights into interactive dashboards.

The project explores:

✅ Borough-level pricing behavior

✅ Room type market distribution

✅ Listing availability trends

✅ Review dynamics

✅ Statistical inference

✅ Market segmentation analytics

---

# 🗂 Dataset Information

**Dataset:** NYC Airbnb Open Dataset

Dataset Characteristics:

- ~38,000 cleaned Airbnb listings
- Multiple boroughs across New York City
- Structured tabular market dataset

Key Variables:

- Listing ID
- Neighborhood Group / Borough
- Room Type
- Price
- Reviews
- Availability
- Minimum Nights
- Host Information

---

# 🔬 Statistical Analysis Performed

The project applied statistical inference techniques for market analysis.

---

## Confidence Interval Analysis

Estimated uncertainty ranges and population behavior.

Applications:

- Mean listing price estimation
- Borough market comparison
- Pricing confidence evaluation

---

## Hypothesis Testing

Statistical testing was conducted to compare market segments.

Examples:

- Room type price comparison
- Borough pricing differences
- Distribution comparison

---

## Exploratory Data Analysis (EDA)

Analysis included:

- Price distributions
- Room type frequencies
- Review behavior
- Availability patterns
- Borough market trends
